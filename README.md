# LangSwitcher

Автоматический переключатель раскладки En/Ru для Windows — аналог Punto Switcher / Caramba Switcher.

## Возможности

- **Автопереключение.** Слово, набранное не в той раскладке (`ghbdtn` → `привет`, `руддщ` → `hello`),
  исправляется после пробела, Enter или Tab, и раскладка переключается для следующих слов.
- **Только слова от 2 букв** (порог меняется в настройках). Одиночные буквы не трогаются.
- **Shift, Shift** (двойное нажатие Shift) — переключить **последнее слово**.
  Работает и после пробела. Повторное нажатие возвращает как было.
- **Shift, Shift при выделенном тексте** — переключить **выделение** (если сразу перед этим
  текст не набирали: выделили мышью, Shift+стрелками и т.п.). Результат остаётся выделенным,
  повторный Shift, Shift возвращает как было. Содержимое буфера обмена восстанавливается.
- **Словарь исключений** — слова, которые никогда не переключаются автоматически.
  Если отменить автопереключение двойным Shift, слово добавляется туда само (можно отключить).
- **Значок в трее** показывает текущую раскладку (EN синий / RU красный; серый перечёркнутый —
  автопереключение выключено).
  - левый клик — включить/выключить автопереключение;
  - правый клик — меню: автопереключение, словарь исключений, настройки, справка, выход.

Не трогаются: слова с цифрами, camelCase-идентификаторы, короткие аббревиатуры капсом (PDF, USB),
слова, нормальные для текущего языка (google.com, don't, кое-что).

## Установка

Требования: Windows 10/11 x64, в системе добавлены раскладки **English (US)** и **Русская**.

### Вариант 1 — готовый exe (проще всего)

1. Откройте страницу **Releases** репозитория и скачайте один из файлов:
   - `LangSwitcher-standalone.exe` — работает сразу, ничего доустанавливать не нужно (~50 МБ);
   - `LangSwitcher.exe` — маленький (~0,3 МБ), но нужен
     [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0) (раздел «Desktop Runtime», x64).
2. Положите exe в постоянную папку, например `C:\Program Files\LangSwitcher\` или `%LOCALAPPDATA%\LangSwitcher\`.
3. Запустите двойным щелчком. Если SmartScreen предупредит о неизвестном издателе —
   «Подробнее» → «Выполнить в любом случае».
4. В трее появится значок EN/RU (если не видно — раскройте стрелку `^` у часов и перетащите значок на панель).
5. Правый клик по значку → «Настройки…» → «Запускать вместе с Windows».

### Вариант 2 — сборка из исходников

Нужен [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0).

```
git clone https://github.com/vitcompany/LangSwitcher.git
cd LangSwitcher\src
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o ..\publish
..\publish\LangSwitcher.exe
```

Автономная версия (без установки .NET):

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o ..\publish-standalone
```

### Удаление

Выключите автозапуск в настройках, выберите «Выход» в меню трея, удалите exe и папку `%APPDATA%\LangSwitcher`.

## Файлы настроек

`%APPDATA%\LangSwitcher\`

| Файл | Назначение |
|---|---|
| `settings.json` | настройки |
| `exceptions.txt` | словарь исключений, одно слово на строку |
| `dict_en.txt`, `dict_ru.txt` | *(необязательно)* дополнительные слова для обучения распознаванию |

## Как это устроено

- `SwitcherEngine.cs` — низкоуровневые хуки клавиатуры и мыши на отдельном потоке. Запоминает
  нажатые клавиши (а не символы), поэтому слово можно «перепечатать» в любой раскладке.
- `LanguageModel.cs` — триграммные символьные модели английского и русского + словари частотных слов.
  Слово переключается, если в другой раскладке оно заметно правдоподобнее.
- `KeyMap.cs` — соответствие клавиш раскладкам US QWERTY и ЙЦУКЕН.
- `SelectionConverter.cs` — конвертация выделения через буфер обмена (в терминалах — Ctrl+Insert / Shift+Insert).

## Ограничения

- Раскладки определяются как «английская» и «русская» по коду языка; таблица клавиш рассчитана на US и стандартную русскую.
- В окна программ, запущенных от администратора, Windows не даёт вводить текст из обычного процесса —
  для них запускайте LangSwitcher тоже от администратора.
- Окна, где Ctrl+C без выделения копирует всю строку (например, VS Code), при Shift, Shift без выделения
  и без только что набранного слова могут вставить конвертированную строку.
